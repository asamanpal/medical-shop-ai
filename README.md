# 🏥 Medical Shop AI Assistant

An AI-powered assistant for medical shops that helps chemists analyze prescriptions, identify medicines, retrieve medicine information, and locate medicines in the shop.

## 🚧 Project Status

Currently under development.

## 🎯 Project Goal

Build a system that can:

1. Upload a prescription image
2. Read the prescription using OCR / AI vision
3. Identify medicines
4. Extract medicine details
5. Retrieve verified medicine information
6. Find the medicine's shelf location
7. Present the results to the chemist

## 🔄 Planned AI Pipeline

Prescription Image
→ OCR / Vision
→ Medicine Extraction
→ Medicine Database
→ Medicine Information
→ Shelf Location
→ Chemist Dashboard
